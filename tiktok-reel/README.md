# Rolka TikTok

Pionowa rolka 9:16 oparta na `products.json`.

Uruchom lokalnie:

```powershell
python -m http.server 8080
```

Otwórz:

```text
http://localhost:8080/tiktok-reel/
```

Kliknij `Nagraj .webm`, poczekaj 16 sekund i wrzuć pobrany plik do TikToka albo przekonwertuj go do MP4 w dowolnym konwerterze.

Tekst lektora:

```text
Szybkie zakupy w cenach dla znajomych?
W katalogu znajdziesz kosmetyki, chemię, kapsułki do prania i kawę.
Wybierasz produkty, dodajesz do koszyka i wysyłasz zamówienie.
Odbiór lokalnie, płatność gotówką albo Blikiem.
Ilości są ograniczone, więc zajrzyj do katalogu.
```
